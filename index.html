01

让视频教程变成可执行的步骤

Bilibili → Agent Runbook

工具项目

看完教程之后，如何把操作过程交给 Agent？这个本地工具串起视频下载、压缩和多模态解析，输出 Runbook、Codex Prompt 与 Hermes Agent Runbook。

公开实现：本地网页配置、连接测试、任务进度与日志、Markdown 预览及下载。模型输出仍需要人工核对。

查看 Bilibili → Agent Runbook 仓库↗
02

把 LangChain 与 RAG 学习串起来

LangChain / RAG

资料整理 · 教程复现

分散在不同教程里的示例不容易对照学习。这个仓库按来源整理三套资料，保留可逐步运行的 Notebook，以及已有输出的对照版本。

整理范围：教程来源、主 Notebook 依赖和学习顺序。示例来自公开教程，来源见仓库 README。

查看 LangChain / RAG 仓库↗
03

给 AI 编程工具一个桌面工作台

BulletFarm

工具项目

同时使用多个 AI 编程终端时，窗口与配置容易散落。BulletFarm 将 Agent 终端、工作区、供应商配置和用量看板放到一个桌面应用里。

公开实现：多终端管理、工作区持久化、配置切换，以及 Skills / Prompts / MCP 的集中管理。当前以 Windows 为主。

查看 BulletFarm 仓库↗
